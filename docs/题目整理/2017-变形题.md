## 5. （综合）

设表达式树的二叉链表存储定义如下：叶结点为操作数（数字），非叶结点为运算符（+ - * /）。设计算法计算该表达式树所表示表达式的值。
typedef struct ExprNode {
char op;//叶结点无用；非叶结点存运算符'+','-','*','/'
int val;//叶结点存操作数
struct ExprNode *lchild, *rchild;
} ExprNode, *ExprTree;
要求：
（1）给出算法的基本设计思想。
（2）根据设计思想，采用C或C++语言描述算法，关键之处给出注释。
答案：
（1）表达式树本身就是运算优先级的直观编码：每个非叶结点代表“先算完左右子树，再用本结点运算”，这恰好是后序遍历。因此算法为递归后序求值：若当前结点为叶结点（lchild == NULL && rchild== NULL），直接返回其数值val；否则先递归求左子树的值L，再递归求右子树的值R；对L、R执行当前结点运算符op对应的运算，返回结果L op R。
（2）实现：
/*后序遍历求表达式树的值*/
int evalExprTree(ExprTree T) {
if (T == NULL) return 0;//空树，防御性处理
if (T->lchild == NULL && T->rchild == NULL)
return T->val;//叶结点：直接返回操作数
int L = evalExprTree(T->lchild);//先算左子树（左操作数）
int R = evalExprTree(T->rchild);//再算右子树（右操作数）
switch (T->op) {//最后用根的运算符合成
case '+': return L + R;
case '-': return L - R;//注意顺序：左op右
case '*': return L * R;
case '/': return L / R;//假设除数非0，整除
}
return 0;
}
