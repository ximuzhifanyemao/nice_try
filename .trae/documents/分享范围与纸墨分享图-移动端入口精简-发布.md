# 分享范围/纸墨分享图、移动端设置精简与 v1.16.8 发布

## Summary

本次处理 6 项需求：

1. 记录页分享不再要求「至少两条记录」，改为可选 **一天 / 一周 / 一个月**；可选择 **总计**（总时长 + 各科目时长）或 **逐日**（日历式展示每天学了多少，不展示具体科目）。
2. 单日分享同样支持两种形态：**总计** 或 **按时间轴**展示。
3. 所有分享图背景改为「纸墨 · 暖纸朱印」主题：暖纸底、水墨山水、朱砂印章，并带行楷「路虽远，行则将至；事虽难，做则必成」。
4. 手机端设置隐藏「简洁模式方向」；「我的」移除与底部 Tab 重复的「计时器」、与首页重复的「政治」入口。
5. 「扫码登录电脑」改到「我的」账号昵称右侧，只保留一个扫码图标，点击直接进入扫码。
6. 全部完成后执行 v1.16.8 发布流程（APK + Windows 安装包 + OTA + GitHub Release + 代码入库）。

### 2）分享数据构建（新增 `src/lib/shareCardData.ts`）

新增纯函数模块，`ShareDialog` 与三个调用方共用：

```ts
export interface ShareRangeInfo {
  mode: ShareMode
  startDate: string
  endDate: string
  dateLabel: string
  title: string
  totalLabel: string
  distributionLabel: string
  secondaryLabel: string
}

export function resolveShareRange(mode: ShareMode, anchorDate: string): ShareRangeInfo
export function buildSummaryPayload(logs: DailyLog[], mode: ShareMode, anchorDate: string): ShareCardData
export function buildCalendarPayload(logs: DailyLog[], mode: 'week' | 'month', anchorDate: string): ShareCalendarCardData
export function buildTimelinePayload(logs: DailyLog[], date: string): ShareTimelineCardData
```

**范围规则（`resolveShareRange`）**

- 日：`startDate = endDate = anchorDate`，`dateLabel` 形如 `2026年11月9日 周日`。
- 周：以周一为起点、周日为终点，`dateLabel` 形如 `11月3日 ~ 11月9日`。
- 月：自然月首尾，`dateLabel` 形如 `2026年11月`。
- 标题：
  - 日：当天 → `今日学习记录`，否则 `单日学习记录`；
  - 周：当前周 → `本周学习总结`，否则 `周学习总结`；
  - 月：当前月 → `本月学习总结`，否则 `月度学习总结`。
- 指标标签：
  - `totalLabel`：`当日总时长（h）` / `本周总时长（h）` / `本月总时长（h）`；
  - `distributionLabel`：`今日投入分布` / `本周投入分布` / `本月投入分布`；
  - `secondaryLabel`：日 → `学习科目（个）`，周/月 → `打卡天数（天）`。

**数据组装**

- 统一过滤 `deleted_at` 为空，并按 `startDate/endDate` 过滤。
- 总计：按科目 `id` 聚合时长、降序；`totalHours` 保留 1 位小数；`checkedDays` 为有记录的日期数；科目名走 `formatSubjectLabel`，颜色走 `subjectCategoryColor`。
- 日历：范围补齐为完整自然周（月视图含上月/下月占位日），每天聚合时长；`isToday`、`isFuture`、`isOutside` 一并计算。
- 时间轴：展开当天所有 `hours > 0` 的科目条目；有时间段的按开始时间升序，无时间段的追加在后；`activity` 用 `formatActivityLabel`。
- 所有分享卡不再传 `motto`（固定文案由渲染层统一绘制）。

## Assumptions & Decisions

- **直接替换多选分享**：不再保留「勾选两条记录」，因为新需求是日/周/月范围分享；多选入口会造成两套分享逻辑并存。
- **分享入口**：记录页页头「分享」默认打开当前浏览周；单日卡片分享打开当天；周总结页分享打开当前浏览周。
- **逐日视图**：周/月都展示日历；月视图补齐整周占位日，但不显示科目明细，只显示每天学了多久。
- **时间轴视图**：按记录里的 `startTime/endTime` 排序；没有时间段的条目排在最后并标注 `--:--`，不丢弃数据。
- **分享图背景**：用 Canvas 程序化绘制纸墨山水，不引入外部图片/AI 生成图，保证离线可用、文案与「行楷」文字准确、每次生成稳定。
- **固定文案**：分享图统一使用「路虽远，行则将至；事虽难，做则必成」，替代原来的随机格言池。
- **扫码入口**：只在手机窄屏、已登录时显示；桌面端不显示（桌面扫码页本身是说明面板）。
- **简洁模式方向**：桌面端保留，手机 App / 手机网页隐藏。
- **发布内容**：当前工作区已有未提交改动属于本次发布范围，一并提交，不做回滚。
