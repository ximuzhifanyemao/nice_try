**B. iframe ↔ 父页面进度桥（public/politics/onepaper.js）**

在 State 区附近新增桥接工具：

- `const EMBEDDED = !!window.parent && window.parent !== window;`
- `let progressBridgeReady = false;`
- `function progressSnapshot()` 返回 `{ mastered, saved, review, visits, last }`（只取学习进度，不含 `theme/font/recite`，避免设备间互相覆盖外观偏好）。

- `saveState()` 在 `localStorage.setItem` 之后追加：`if (progressBridgeReady) postToParent('kaoyan:politics-progress', { progress: progressSnapshot() })`。
- 新增 `message` 监听（校验 `event.source === window.parent`）：
  - `kaoyan:politics-request-state` → `postToParent('kaoyan:politics-ready', { progress: progressSnapshot() })`。
  - `kaoyan:politics-hydrate` → 用父页面传来的并集覆盖 `S.mastered / S.saved / S.review / S.visits / S.last`，`progressBridgeReady = true`，`saveState()`，`render()`。
- `init()` 末尾不主动广播，等待父页面在 `iframe.onLoad` 后发 `kaoyan:politics-request-state`（避免父页面监听器尚未挂载时丢失消息）。

**C. 父页面桥梁（src/pages/Politics.tsx）**

- 引入 `useAuth`、进度读写函数。
- `iframe.onLoad`：若已登录，向 iframe 发 `{ type: 'kaoyan:politics-request-state' }`。
- 消息处理扩展（继续用 `event.source === frameRef.current?.contentWindow` 校验）：
  - `kaoyan:politics-back`：保持现有回退逻辑。
  - `kaoyan:politics-ready`：取 `remote`（挂载时已 `fetchPoliticsProgress(user.id)` 预取）与 iframe 本地进度，`mergePoliticsProgress` 合并 → 向 iframe 发 `{ type: 'kaoyan:politics-hydrate', progress }` → `savePoliticsProgress(user.id, merged)`。
  - `kaoyan:politics-progress`：写入 `latestProgressRef`，800ms 防抖后 `savePoliticsProgress`。
- 组件卸载时清除防抖定时器，并对尚未落库的最新进度补一次保存（`void save...`，不阻塞）。
- 未登录：不预取、不发 request-state，政治页继续纯本地使用。

**D. 新增 src/lib/politicsProgress.ts**

- `export interface PoliticsProgress { mastered: number[]; saved: number[]; review: number[]; visits: string[]; last: number | null }`
- `sanitizeProgress(value: unknown): PoliticsProgress`：数组过滤非法项；`visits` 去重排序后 `slice(-180)`；`last` 仅接受数字。
- `mergePoliticsProgress(remote, local)`：`mastered/saved/review` 数字并集；`visits` 并集排序取最后 180 天；`last` 优先本机值，其次远端。
- `fetchPoliticsProgress(userId)`：`supabase.from('politics_progress').select('state').eq('user_id', userId).maybeSingle()`；表不存在/网络失败时 `console.warn` 并返回 `null`（不影响政治页使用）。
- `savePoliticsProgress(userId, progress)`：`upsert({ user_id, state: progress, updated_at: new Date().toISOString() }, { onConflict: 'user_id' })`；失败仅 `console.warn`。

**E. 数据库**

- 新增 `supabase/migrations/003_politics_progress.sql`：

```sql
CREATE TABLE IF NOT EXISTS public.politics_progress (
  user_id    UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  state      JSONB NOT NULL DEFAULT '{}'::jsonb,
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

ALTER TABLE public.politics_progress ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "politics_progress_select_own" ON public.politics_progress;
CREATE POLICY "politics_progress_select_own"
  ON public.politics_progress FOR SELECT USING (auth.uid() = user_id);

DROP POLICY IF EXISTS "politics_progress_insert_own" ON public.politics_progress;
CREATE POLICY "politics_progress_insert_own"
  ON public.politics_progress FOR INSERT WITH CHECK (auth.uid() = user_id);

DROP POLICY IF EXISTS "politics_progress_update_own" ON public.politics_progress;
CREATE POLICY "politics_progress_update_own"
  ON public.politics_progress FOR UPDATE USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);

GRANT SELECT, INSERT, UPDATE ON public.politics_progress TO authenticated;
```

- 「墨夜」旧用户迁移到「深色」（保留暗色观感），而不是「纸墨」；系统深色偏好兜底也用「深色」。

- 数据库不可用（未执行 SQL / 网络失败）时政治页继续纯本地可用，不弹错误打扰用户。
- 待办只调整手机端顺序，桌面双栏布局不动。
