# 考研硬件计时器 - 购买清单

用于 DIY 一个可蓝牙回传打卡的 ESP32 计时器（配套 `hardware/esp32_timer/esp32_timer.ino`）。

## 必买（约 10–20 元）

| 物品 | 规格建议 | 参考价 | 用途 | 备注 |
|---|---|---|---|---|
| ESP32 开发板 | ESP32-DevKitC / NodeMCU-32S；或更小的 ESP32-C3 | 9–15 元 | 主控 + 蓝牙 | 优先选 ESP32（支持 I2C 屏的资源多） |
| 0.96 寸 OLED | I2C，SSD1306，4 针 | 5–8 元 | 显示倒计时 | 蓝/白均可 |
| 轻触按键 ×2 | 12mm，间距合适 | 1–2 元 | 开始/结束 | 也可买带帽的 |
| 蜂鸣器 | 有源 5V 有源型 | 0.5–1 元 | 结束提醒 | 有源=通电就响，代码更简单 |
| 面包板 | 400 点 | 2–4 元 | 免焊接连线 | 新手首选 |
| 杜邦线 | 公对公/母对公，若干 | 1–3 元 | 连接各模块 | |

## 可选（提升体验）

| 物品 | 用途 |
|---|---|
| 锂电池 + 充电模块（TP4056） | 便携无线，摆脱 USB 供电 |
| 3D 打印外壳 / 收纳盒 | 保护杜邦线，更整洁 |
| USB 数据线 | 烧录固件（若手头没有 Type-C/Micro-USB 线） |

## 合计预算

- **最小可用：约 15–20 元**（板 + 屏 + 按键 + 蜂鸣器 + 面包板 + 杜邦线）
- 加锂电池 + 外壳：约 25–35 元

## 注意

- 首次开发建议**先买面包板方案**，验证通了再考虑焊接定型。
- ESP32 请在 [arduino.cc](https://www.arduino.cc/) 官网安装 Arduino IDE，并在「开发板管理器」里装 `esp32` 包。
- 烧录需 USB 数据线（很多充电线不能传数据，别只带充电线）。
