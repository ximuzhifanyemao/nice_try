## 一、软件简介

DiveDeep学习打卡追踪系统是一款面向学生群体的学习管理类应用软件，支持 Web 网页、Android 移动端与 Windows 桌面端三种运行形态。软件围绕"专注学习、每日打卡、持续追踪"设计，提供学习打卡记录、科目时长统计、每周学习趋势分析、自定义倒计时、学习计时器、健康打卡、英语打卡与词汇学习、成就激励等完整功能。所有数据通过 Supabase 云端服务进行多端同步，用户更换设备后数据不丢失。

## 二、运行环境

1. 硬件环境：

   - 处理器：1GHz 及以上；

   - 内存：2GB 及以上；

   - 存储空间：100MB 及以上可用空间；

   - 显示分辨率：建议 1280×720 及以上。
2. 软件环境：

   - Web 版：支持 Chrome、Edge、Safari 等主流浏览器；

   - Android 版：Android 12.0 及以上系统；

   - 桌面版：Windows 10 及以上系统。

## 三、软件的安装与启动

1. Web 版：在浏览器地址栏输入系统网址并回车，即可直接访问，无需安装。
2. Android 版：获取 APK 安装包后，点击安装包按系统提示完成安装；首次安装需允许"安装未知来源应用"权限。安装完成后点击桌面图标启动。
3. Windows 桌面版：运行安装程序（MSI 或 EXE），按向导提示完成安装；安装完成后可从开始菜单或桌面快捷方式启动。

## 四、用户注册与登录

1. 首次使用需注册账号：进入登录页，点击"注册"，填写邮箱（或手机号）与密码，确认后完成注册。
2. 已有账号直接输入账号密码登录。
3. 网页版支持二维码登录：网页端展示登录二维码，已登录的移动端扫码确认后即可免密登录。
4. 忘记密码：登录页点击"忘记密码"，输入注册邮箱，系统将发送密码重置邮件至该邮箱；点击邮件中的重置链接进入重置页面，按提示设置新密码后即可用新密码登录。
5. 登录后在"我的"页面可查看和修改个人资料，支持退出登录。

## 五、首页功能说明

首页为用户每日进入的第一界面，集中展示关键信息：

1. 打卡提醒：提示今日是否完成打卡，引导用户进入打卡流程。
2. 连续打卡天数与本周进度：展示最近连续打卡天数、本周各科目完成情况。
3. 倒计时与阶段提示：自动根据距考试（或自定义目标）的天数切换备考阶段（如基础期、强化期、冲刺期），并展示每日格言。
4. 桌面全功能模式首页采用双栏布局：左侧为信息区，右侧为日历区，一目了然。

## 六、学习打卡与记录管理

1. 新增打卡：点击"新增记录"，选择科目、记录类型，填写时长与备注后保存；同一饮食分类当日多次记录会自动合并展示。
2. 记录列表：按日期查看全部学习记录，支持按科目筛选。
3. 编辑与删除：对已有记录可修改内容或删除；删除的记录进入回收站。
4. 回收站：可恢复误删记录，或彻底删除。

## 七、学习计时器

1. 在计时页选择学习科目，点击开始，系统进行专注计时。
2. 计时完成后自动生成一条学习记录，时长计入对应科目的当日统计。
3. 支持暂停、继续、放弃等操作；Web 端与移动端计时状态可同步。
4. 桌面挂件提供专注计时能力，随时查看剩余时长。

## 八、日历功能

1. 按月份展示日历，已打卡的日期显示打卡标记。
2. 点击任意日期，可查看该日全部打卡明细（学习、健康、英语等）。
3. 支持前后翻月，快速回顾历史学习情况。

## 九、健康打卡

1. 饮食记录：选择餐次（早餐、午餐、加餐）后，可从预设食物库、收藏食物或历史记录中快速添加，也可手动输入。
2. 饮水记录：记录每日饮水杯数。
3. 健康数据随打卡记录一并保存，并纳入每日汇总和每周统计。

## 十、英语打卡与词汇本

1. 英语打卡：每日完成英语学习打卡，查看完成状态与连续记录。
2. 词汇本：管理待记词汇，支持记忆状态标记。
3. 单词查询：支持在线查询与离线词典查询，便于随时核对释义。
4. 每日英语内容：每日推送一句英文内容供学习积累。

## 十一、目标与倒计时

1. 设置个人目标（如考试日期、目标科目），系统自动计算剩余天数。
2. 首页倒计时根据剩余天数自动展示备考阶段。

## 十二、数据统计与导出

1. 学习统计：按日、周、月维度展示各科目学习时长汇总。
2. 趋势图：以图表形式展示每周学习时长变化趋势。
3. 周期筛选：支持自定义起止日期查看区间内统计数据。
4. 数据管理：支持查看"我的记录"；提供数据导出功能，方便备份。

## 十三、成就系统

1. 完成特定打卡目标（如连续打卡、累计时长达标）时自动解锁成就。
2. 解锁成就时页面弹出奖励提示，可在成就页查看全部成就及解锁进度。

## 十四、桌面挂件模式

Windows 桌面端支持两种窗口形态：

1. 紧凑挂件模式：悬浮于屏幕桌面的小窗口，默认置顶显示，提供打卡状态快捷查看与计时功能，可自由拖动位置。
2. 全功能模式：点击"全部功能"按钮展开为完整窗口，显示全部页面与日历，可随时切回紧凑模式。

## 十五、设置与主题

1. 主题切换：支持浅色、深色及多种预设主题，一键切换，全局生效。
2. 应用信息：可查看当前版本号。
3. 更新检测：启动时自动检查新版本，检测到更新时提示下载更新。

## 十六、常见问题

1. 忘记密码怎么办？——在登录页点击"忘记密码"，输入注册邮箱后系统会自动发送重置链接到该邮箱；点击邮件中的链接按提示设置新密码，即可用新密码登录。若未收到邮件，请检查垃圾邮件箱，或确认输入的邮箱为注册邮箱。
2. 数据会丢失吗？——数据云端同步，卸载重装后重新登录即可恢复。
3. 计时记录未生成怎么办？——请确认计时达到最小记录时长，且保存时网络正常。
4. 软件如何更新？——Web 版直接访问最新网址；移动端与桌面端在检测到新版本后按提示下载安装即可。
